# Mind — descargas y actualizaciones

Este repositorio distribuye los paquetes portables y las actualizaciones de Mind. El código fuente se mantiene en un repositorio privado.

Todavía no hay una versión estable publicada en este canal.

Las instalaciones que incorporen el actualizador automático comprobarán las nuevas versiones estables al iniciar Mind. Los paquetes se verifican mediante un canal firmado digitalmente. Sin conexión se conserva la versión instalada.

Una instalación anterior al actualizador automático necesita recibir una vez un paquete que lo incluya. Las versiones preliminares no se distribuyen automáticamente por el canal estable.
